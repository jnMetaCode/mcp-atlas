# 维护工具离线演示

日期：2026-10-22。数据来自仓库内的合成测试样例，没有访问或验证真实 MCP。

## Registry 导入

首次执行：

```text
Registry 同步完成：2 项观察、2 项内容变化。
```

再次执行相同样例：

```text
Registry 同步完成：2 项观察、0 项内容变化。
```

两个候选的演示命名空间是 `io.github.fixture/document-tools` 和 `io.github.fixture/remote-tools`。它们只保存在忽略发布的 `.maintenance/demo-registry` 中，未加入正式目录。

示例能说明分页、去重与报告流程工作，不能说明真实 Registry 当前包含这些项目。

## 来源链接检查

| 合成地址 | 预设响应 | 结果 |
|---|---|---|
| fixture.example/ok | HEAD 200 | reachable |
| fixture.example/head-disabled | HEAD 405，GET 200 | reachable |
| fixture.example/missing | HEAD 404 | broken |
| fixture.example/limited | 三次 HEAD 429 | rate_limited |

没有向这些域名发出网络请求。样例固定响应只用于验证分类、回退与重试。

# 第五轮实现与验证记录

日期：2026-10-23。补齐首版排序规则。

目录新增“最近上游更新”排序，使用可选的 `upstreamUpdatedAt` 日期，未知日期放在已确认日期之后，再按最近审核和稳定 ID 排列。切换排序返回第一页，排序参数能够在分享链接和重新进入页面后恢复。

相关度排序仍先匹配精确名称、别名和服务标识，然后匹配名称包含与描述；同分时优先有指南的项目，再按最近审核和稳定 ID。作者身份不参与加权。无查询时保持最近审核顺序。

Schema 允许可选上游日期，同时要求来源声明对应字段，来源核对时间不得早于更新事件。未来日期、非法日期和无来源日期被拒绝。没有批量填充种子数据日期，也没有从 Registry 的观察时间推断项目发布时间。当前 32 个项目均未提供此字段，选择该排序时会展示回退说明。

新增四项单元测试覆盖日期顺序与未知回退、作者不加权、排序链接还原和日期证据约束；新增一项实际组件测试覆盖排序切换、分页重置与重挂载恢复。单元测试共 67 项通过，DOM 交互测试共 10 项通过。浏览器布局、线上发布与真实 MCP 连接仍未验证。

验收状态和实施差异已同步到 [首版验收对照](首版验收对照.md)，字段填写规则见 [贡献指南](../CONTRIBUTING.md)。

## 与设计方案的实施差异

指南当前采用受控 JSON 和 React 组件渲染，没有引入 MDX 编译；这减少首版内容执行面，但尚未提供 MDX 编辑体验。排序提供相关度、最近审核和最近上游更新；相关度同分时依次按指南覆盖、审核日期和稳定 ID 排列。上游日期必须附来源，目前种子项目尚无已核对的该字段，页面明确说明回退顺序，不把本站审核时间当成上游更新时间。未接入 Stars 或评分数据。

响应头模板需要部署平台实际支持后才生效；不能把静态文件存在作为 HTTP 安全策略生效的证据。性能、视觉布局、无障碍和真实用户任务测试也不在单元测试或 jsdom 的证明范围内。

## 下一阶段的顺序

1. 将真实公开 GitHub 仓库地址写入配置，运行远程 CI 并配置保护规则。
2. 在可运行浏览器的环境完成桌面、360px 移动端和键盘流程，修复实际发现的问题。
3. 在真实 HTTPS 域名发布，核对响应头、404、sitemap、下载和复制；保留上一发布包并演练回滚。
4. 补充作者作品材料和至少一组有环境、版本、日期与范围的真实 MCP 连接记录。
5. 执行需求中的用户任务测试，核对上游更新日期，再决定扩充收录量。

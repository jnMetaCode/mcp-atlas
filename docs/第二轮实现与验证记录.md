# 第二轮实现与验证记录

此文件保留第二轮历史；维护工具的后续进展见 [第三轮实现与验证记录](第三轮实现与验证记录.md)。

版本：0.2.0 · 日期：2026-10-22。延续首轮实现，不代表全部上线验收完成。

## 本轮结果

- 收录从 8 个扩充到 32 个真实项目，8 类场景均有内容。
- Figma、Slack、Atlassian 各有官方与社区实现，通过服务页关联，仍保留独立项目身份。
- 加入 10 篇 VS Code 配置指南，明确适用系统、前置条件、JSON 示例、来源与审核日期。
- 指南全部属于文档核对，不声称第三方 MCP 已安装、连通或完成任务。
- 源码/费用筛选、动态计数、已选标签、24 项分页、非法 URL 参数清理、浏览器前后退状态恢复已实现。
- 对比选择可在当前会话中保留，最多三个；移除后同步会话记录。
- 贡献页支持项目纠错预填、字段补充、复制与下载，配置实际 GitHub 仓库后可打开待用户确认的 Issue 草稿。

## 数据与内容设计

目录 Schema 升至 2；保留项目级摘要字段，同时增加接入变体、字段级来源、指南引用与测试记录。

筛选运行方式和认证方式时，两项条件必须落到同一个接入变体，防止把本地版免密与远程版 OAuth 拼成不存在的接入方式。

同项目的不同认证选项可以同时存在。Exa 托管端点的匿名与登录方式已分明记录，因此不能简单根据项目级“未确认”摘要排除已核对的匿名接入。

费用尚未逐项核验，仍保持 unknown；不因源码有 MIT 许可就宣称服务免费。Exa 客户端仓库许可不被推断为其托管服务端源码许可。ElevenLabs 使用当前托管服务资料，未把已弃用的本地实现当作当前推荐。

公开数据包含目录、分类/服务索引、单项目记录和指南快照，使用同一 snapshot。撤回记录不进入公开目录与发现路由。源码中的历史条目可保留供审计。

## 已通过检查

- 23 项自动测试：搜索、组合筛选、分发条件一致性、未知值、分页边界、URL 规范化、去重、Schema 负向校验、引用、身份和费用证据、配置语法、贡献草稿与链接限制。
- Next.js 生产构建及 TypeScript 类型检查。
- 92 个路由输出、89 个 HTML 文件。
- 静态产物内部链接和资源目标、32 个项目快照、10 篇指南及 sitemap 完整性检查。
- 16 个 Playwright 测试可正常被发现，覆盖桌面和 360px 移动视口，包含剪贴板失败分支。
- 本地 Node v23.11.0 的 1000 条构造数据检索及六维计数基准，100 次运行 p95 为 15.23ms。该结果不包含浏览器渲染，不等于需求中的端到端性能验收。

## 验证限制

尝试执行浏览器测试时，Python 静态服务绑定本地端口被沙箱拒绝，返回 PermissionError / Operation not permitted。测试未运行到浏览器页面，因此没有将 16 项浏览器测试、移动布局、复制或下载动作标记为通过，也没有生成经过检查的截图。

CI 已加入 Chromium 准备和浏览器测试步骤；配置存在不代表远程 CI 已运行或通过。

本轮复查 Sites 源码仓库域名，Node DNS 返回 ENOTFOUND。保留原有 project_id，不重复注册、不声称部署完成。生产静态文件仍保存在 out/。

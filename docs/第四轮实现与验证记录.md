# 第四轮实现与验证记录

日期：2026-10-23。版本：0.4.0。

## 完成内容

新增真实组件 DOM 测试，覆盖目录分享 URL、检索、筛选标签、浏览器后退、分页、比较上限、会话恢复、配置复制、申请校验与纠错预填。修复分享比较列表未同步会话、表单纯空格输入及复制失败后仍显示成功的问题。

站点绝对地址由 `data/site.json.origin` 和构建环境 `SITE_URL` 统一决定。非法配置直接报错。作者展示页仍等待真实作品，暂设 noindex 并移出 sitemap；取消缺少依据的全站固定最后更新时间。

新增托管响应头模板、静态部署指南和发布打包脚本。发布包仅从 `out/` 收集静态文件，拒绝符号链接和隐藏文件，附逐文件哈希清单、部署说明及整包 SHA-256；不包含源码凭证和维护状态。打包是本地产物操作，不代表完成上传。

## 验证证据

- `npm test`：60 项通过。
- `npm run test:dom`：9 项通过。
- `npm run build`：生产构建、类型检查及 92 项静态生成完成。
- `npm run check:export`：89 个 HTML、32 个项目、10 篇指南，内部资源目标完整。
- `python3 scripts/package-static.py`：246 个静态文件，ZIP CRC 校验通过，生成发布包及 SHA-256 文件。

测试使用 jsdom，无需启动 HTTP 服务。tsx CLI 的进程通信监听被环境拒绝后，改用 Node 导入其转换器执行同一测试；不申请或改变网络权限。

## 验证边界与后续事项

DOM 测试不验证视觉布局、真实浏览器剪贴板权限、实际 MCP 连接和线上响应头。当前没有新增成功的浏览器或线上部署证据。公开 GitHub 仓库和作者作品仍未提供，不能填入虚构内容。自动维护的联网采集及远程 CI 仍需在实际可联网环境运行。

发布操作参见 [静态部署指南](静态部署指南.md)。默认预留域名不能作为已上线的证明。
